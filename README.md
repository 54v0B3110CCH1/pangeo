# PanGeo

Archivio aperto di difesa e geopolitica di 198 Stati: forze armate, basi (solo a livello di città), alleanze, aziende e proprietà, appalti, sicurezza privata, notizie dal vivo con il livello di affidabilità delle fonti.

- **Sito**: https://54v0b3110cch1.github.io/pangeo/
- **Tabelle aperte, datate e con fonti** (CSV e JSON, senza account): https://54v0b3110cch1.github.io/pangeo/tabelle.html
- **Dati dal vivo del telefono**: `live.json`, aggiornato ogni 3 ore dal programma PanGeo in Termux.
- **Programma**: cartella `programma/`. Sul telefono il codice nuovo non si installa da solo: serve `python castello.py approva`.

Solo informazioni pubbliche con fonte. Numeri di uomini e mezzi solo come stime pubbliche. Nessun dettaglio operativo.
